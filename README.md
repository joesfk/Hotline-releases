# Hotline and ForeverBags

Two WoW: Forever addons, made by Joe for Joe, Sam and Alex:

- **Hotline**: torches that show how close your friends are, shared notes, and new things that arrive one night at a time.
- **ForeverBags**: all your bags in one window, with search, sorting and sections. It sells junk and repairs at vendors.

## Install them (once)

1. Open the [newest release](../../releases/latest) and download **Forever-Updater.exe**.
2. Run it. Windows may say it's from an unknown publisher: click **More info**, then **Run anyway**.
3. If it can't find World of Warcraft by itself, press **Change...** and pick your World of Warcraft folder.
4. Both addons are ticked. Untick one if you don't want it, then press **Install both** (or **Install Hotline**, or **Install ForeverBags**).

Had **Hotline-Updater.exe** before? Download Forever-Updater.exe once instead. It remembers your WoW folder.

## Every night

Run **Forever-Updater.exe** before you play and press **Update** if it offers one. If WoW is already open, type `/reload` afterwards. The updater keeps itself up to date too, so you only download it once.

Your notes and settings are never touched: they live in WoW's `WTF` folder, and the updater only changes `Interface\AddOns\Hotline` and `Interface\AddOns\ForeverBags`.

## New things

Hotline is the one that grows. Joe switches new features on one night at a time. When Joe does, a "New tonight" slip pops up in game with a ring and shows you how it works. `/hl features` lists what's on. ForeverBags stays a simple bag.

This repository only holds the release files. The updater never asks for passwords and never touches anything outside those two addon folders.
