# Hotline

Hotline is a WoW: Forever addon for Joe, Sam and Alex: torches that show how close your friends are, shared notes, and new things that arrive one night at a time.

## Install it (once)

1. Open the [newest release](../../releases/latest) and download **Hotline-Updater.exe**.
2. Run it. Windows may say it's from an unknown publisher: click **More info**, then **Run anyway**.
3. If it can't find World of Warcraft by itself, press **Change...** and pick your World of Warcraft folder.
4. Press **Install Hotline**.

## Every night

Run **Hotline-Updater.exe** before you play and press **Update** if it offers one. If WoW is already open, type `/reload` afterwards.

Your notes and settings are never touched: they live in WoW's `WTF` folder, and the updater only changes `Interface\AddOns\Hotline`.

## New things

Joe switches new features on one night at a time. When he does, your phone rings in game and shows you how it works. `/hl features` lists what's on.

This repository only holds the release files. The updater never asks for passwords and never touches anything outside the Hotline folder.
